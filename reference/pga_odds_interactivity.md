# Get odds interactivity configuration

Returns the PGA Tour's odds-widget configuration (book partners, UI
settings). Returned as a nested list since the schema varies and is
mostly frontend wiring.

## Usage

``` r
pga_odds_interactivity()
```

## Value

The parsed JSON response as a nested R list.

## Examples

``` r
if (FALSE) { # \dontrun{
pga_odds_interactivity()
} # }
```
